# ─────────────────────────────────────────────────────────────────────────────
# wisardpkg: instalar SEPARADAMENTE, e do branch develop
# ─────────────────────────────────────────────────────────────────────────────
#
#   pip install pybind11
#   pip install --no-build-isolation "git+https://github.com/IAZero/wisardpkg.git@develop"
#
# Três coisas que dão errado se ignoradas:
#
# 1. `pip install wisardpkg` traz a versão 1.6.3, que é o branch `master` e tem
#    só Wisard, ClusWisard e Discriminator. A RegressionWisard existe apenas no
#    branch `develop` (versão 2.0.0a7). O comando acima traz a certa.
#
# 2. O `--no-build-isolation` é obrigatório. Sem ele o build falha com
#    `ModuleNotFoundError: No module named 'pybind11'`, porque o pacote precisa
#    do pybind11 em tempo de compilação e não o declara direito.
#
# 3. É extensão C++ compilada, não Python puro. O arquivo instalado tem nome do
#    tipo `wisardpkg.cpython-39-darwin.so`, ou seja, é específico da versão do
#    Python e do sistema operacional. Não adianta copiar o .so entre máquinas,
#    e por isso ele não é versionado neste repositório.
#
# Conferir se deu certo:
#
#   python3 -c "import wisardpkg as w; print(w.__version__, hasattr(w,'RegressionWisard'))"
#
# Deve imprimir:  2.0.0a7 True
#
#

# ─────────────────────────────────────────────────────────────────────────────
